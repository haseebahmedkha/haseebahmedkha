## 🧪 Testing Philosophy

```
What I believe about good test automation:

✓ Tests should be independent     — no test depends on another
✓ Data should be dynamic          — faker.js, not hardcoded values
✓ Framework over scripts          — POM, fixtures, types, helpers
✓ CI/CD is not optional           — if it's not in the pipeline, it doesn't exist
✓ Documentation completes the work — test plan + test cases + reference guide
```
